# HIG-aware implementation review

Inspect the implementation and identify the Apple platforms, framework, devices, and supported input methods. Retrieve relevant component, pattern, input, accessibility, and privacy rules. Distinguish automated findings from manual design questions. Check semantics, focus order, labels, keyboard and pointer paths, Dynamic Type, VoiceOver, Reduce Motion, contrast, state handling, destructive-action recovery, and permission denial. Cite rule IDs and source URLs, and explicitly list anything that cannot be verified from code.
